# 小型装修公司 AI 赋能方案

面向 1—10 人装修公司、全屋定制门店和独立设计团队的 AI 赋能项目首版。

## 项目目标

把 AI 用到装修公司的真实业务环节中，帮助团队：

- 稳定产出小红书、视频号和朋友圈内容
- 缩短客户需求整理、方案表达和报价沟通时间
- 统一项目资料、案例和客户跟进流程
- 将个人经验沉淀为团队可复用的标准流程
- 用较低成本验证线上获客与线下成交的结合方式

## 适用对象

- 小型装修公司
- 全屋定制门店
- 独立室内设计师
- 住宅收纳与老房改造团队

## 使用方式

1. 先用诊断问卷了解企业现状。
2. 选择一个最急迫的业务环节做 7 天试点。
3. 用模板完成一次真实项目。
4. 记录节省的时间、内容产出量和有效线索。
5. 再逐步扩展到内容、设计辅助、客户管理和标准化办公。

## 核心原则

AI 负责提速、整理、生成初稿和提醒；专业人员负责判断、设计、沟通和最终交付。
